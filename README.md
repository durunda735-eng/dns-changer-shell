# dns-changer-shell
This repo will make it so you can change FASTLY your DNS provider with no mess on Wi-Fi advanced settings.

# What file do i install for my OS?
Note: the file name for Linux and MacOS are same. Dont get confused.
<br>

| Operating system |   | Script                         |
|-----------------|---|--------------------------------|
| For Windows     |   | ```dns-changer-windows.bat``` |
| For Linux       |   | ```dns-changer-mac-linux.sh```    |
| MacOS           |   | ```dns-changer-mac-linux.sh```    |
<br>
